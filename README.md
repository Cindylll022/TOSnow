# TosNOW
## Introduction
TosNow is a AI powered tool to assist understanding in Terms of Server and Privacy Policy. After detecting the important policies, our extension uses Gemini 1.5-flash AI model to simplify the terms and conditions to generate a summary. 

## How to Download
Download file to local through the repository. In chrome, open extension tab, load unpack to upload TosNOW to add to extensions.
